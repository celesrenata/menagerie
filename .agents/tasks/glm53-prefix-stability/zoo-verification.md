# GLM-5.3 prefix stability (Zoo): verification

Iteration 1 (no zoo-review.json existed). Branch `feat/omniroute-tier-dropdown-feat005`, no worktree.

## Changes

- `src/core/task/Task.ts`: the per-request path no longer calls `compactHistoricalEnvironmentDetails`. Already-sent history, including every earlier `<environment_details>` block, now goes out verbatim. A code comment records why. Compaction still runs at condense time (`summarizeConversation`, condense/index.ts:339). The unused import was removed. This is the default for every profile, with no setting.
- `src/core/task/compactEnvironmentDetails.ts`: doc comment only. It now says the function is condense-only and must not be used in the request path.
- `src/api/providers/openai.ts` `getModel()`: an OmniRoute profile (`isOmniRoute`: openai provider plus `openAiIsOmniRoute`) defaults `preserveReasoning: true` when the custom model info leaves it unset. An explicit `false` still wins. Non-OmniRoute profiles are unchanged. This is a provider-level default and adds no new user setting. The shared defaults object is not mutated. With this flag, `buildCleanConversationHistory` keeps the reasoning block, and `convertToOpenAiMessages` emits it as `reasoning_content`.

## Tests added

- `src/core/task/__tests__/Task.spec.ts`, test "keeps turn N's request as a byte-stable prefix of turn N+1 for an OmniRoute profile". It sets up a real OmniRoute `OpenAiHandler` and spies on `createMessage`. It calls `attemptApiRequest` twice for the same task (turn N, then N+1 after appending assistant(reasoning+tool_use) and user(tool_result+env)). It converts both captured histories with `convertToOpenAiMessages` and asserts:
    - `JSON.stringify(N+1.slice(0, N.length)) === JSON.stringify(N)`, which is a byte-for-byte prefix.
    - The earlier env snapshots (`t1`, `t2`) are still present.
    - Both assistant turns carry `reasoning_content` ("first plan", "second plan").
    - Run against the pre-change `Task.ts`/`openai.ts` (stashed), the test fails. The received prefix shows the env-only user message removed and replaced by the assistant turn, which is the exact pattern in the root-cause report.
- `src/api/providers/__tests__/openai.spec.ts` `getModel`: OmniRoute defaults to `preserveReasoning` true. An explicit false is kept. Non-OmniRoute (`false`/`undefined`) stays unset. The shared defaults are not mutated.
