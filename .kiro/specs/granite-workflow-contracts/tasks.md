## Dependencies / safe parallelization

```text
0.1 ─┬─> 0.2 (external serving preflight) ─> 1.2
     ├─> 0.3 ─────────────────────────────> 1.7, 5.1
     └─> 0.5 ─────────────────────────────> 2.1
1.1 ─> 1.2/1.3/1.4/1.5/1.6 ─> 1.7 ─> 2.1
2.2 ─> 2.3 ─> 2.4 ─> 2.5 ─> 2.6
2.1 + 2.6 ─> 3.1–3.6 ─> 3.7 ─> 4.1–4.4 ─> 5.1–5.5
```

**Can parallelize safely:** contract schemas, quality-fixture curation and template preflight; queue implementation and cache unit tests once request types freeze; spec projection and pure traceability after schema freeze; UI mocks and metrics after event payloads freeze. **Cannot parallelize blindly:** migrations touching `global-settings.ts`, `ParallelTasksTool.ts`, shared task lifecycle reducers, or the authoritative gate and revision schema.

## Acceptance demonstrations

1. One source file and one change request produce a short, citation-grounded requirement/contract summary without tool calls from Granite; no unrelated tab opens.
2. Two Granite analysis jobs generate concurrently; a third is queued, with no lost permits after timeout/cancel; no inference-slot count is borrowed from the 9B reader route.
3. Contradictory requirements are reported with citations and never silently resolved as facts; a deeper capable model or human owns adjudication.
4. A strict-mode spec with three tasks and a dependency cycle is rejected before dispatch. A valid graph compiles into existing `TaskDag`, without creating a second scheduler.
5. A coder reports success, but an executable acceptance test fails: task is **not verified** even if Granite's text says PASS. Fixer/re-run records old failure and new evidence.
6. Editing one depended-on source or requirement invalidates its dependent evidence and checks, not unrelated completed work.
7. Closing and reopening task panel does not terminate running work; status is reconstituted from persisted authoritative state, not checkbox appearance.
8. On absent/unhealthy Granite route, optional analysis may be skipped with visible cause; strict required analysis escalates or blocks, never fails open.
